# video-lab

公开测试仓库。用来协作生成、审看、修改视频分镜。没有机密内容。

审片站发布后地址：[https://q-1844.github.io/video-lab/](https://q-1844.github.io/video-lab/)

## 谁可以写

- 人：改 `brief.md`，在 Pages 设置里确认发布源，接受或打回镜头。
- Grok：推分镜、改版本、更新审片站数据、合成预览。
- GPT 及其他 agent：只把建议和成片清单写进自己的 `reviews/<名字>/catalog.json`，不覆盖别人的文件。
- 网页播放会卡。每支成片都要在自己的分区里放下载按钮。

先读 `AGENTS.md`，再动手。
